# 通过潜空间轨迹补全发现中间目标

我们想知道，智能体能否只根据当前观测和一个长程任务，发现演示中少见但能可靠执行的中间目标，再把这些目标串起来，提高它在新世界里的终局成功率。核心假设是，一段轨迹可以像一张被遮挡的图一样从两端向中间补全，而且同样的两端可以容纳多种可执行的路线。

**Worth reaching** 指值得去追的中间目标。一个潜目标值不值得追，看的是：用同一个执行器追它若干步，在实际剩余预算下对终局成功率和到达时间有什么影响。没有人预先定义中间目标，也没有人工设定的到达判据。对演示中少见的路线，用独立演示估计支持度，并用独立的前瞻执行检验可靠性。

**论文主张。** 补全潜空间轨迹、在潜空间生成子目标、以潜目标为条件的执行器，这些部件都有先例（Diffuser、HorizonFlow、HDFlow、HWM、Director、HIQL）。论文的主张（A）是：**潜目标的含义就是追它之后会发生什么。** 执行器直接以 z 为条件追至多 k 步，这是一个 option，不需要解码出目标状态，也不需要到达判据。方法（C）是一个以预算为条件的 option 价值 Q(h, g, z, k, b)：同一个价值选择候选和它的时长，把编码后的终局目标始终作为候选之一，并决定何时中断、何时重新采样；它先在演示档案的事后 option 上离线拟合，再用执行器自己的尝试在线修正。支撑性的发现（B）是：模型似然不等于价值，预算会改变哪个目标值得去。最初的方案把目标定义为解码器 p(s | z) 给出的一片状态区域，但 E1 中区域目标在所有环境里都没有超过点目标，所以解码器不再是方法的一部分。实验优先级和与已有工作的对照见[研究计划](latent-subgoal-research.md#positioning-against-prior-work)和[实施计划](../PLAN.md#paper-experiments-by-priority)。

## 从两端预测中间

在 I-JEPA 中，模型看到图像的一部分和被遮挡块的位置，预测该块的特征。训练答案来自编码过的完整图像。我们把图像上的空间位置换成轨迹上的时间位置，把可见的上下文换成起点历史和终局条件。[I-JEPA 原论文第 3 节与第 8 节](https://openaccess.thecvf.com/content/CVPR2023/papers/Assran_Self-Supervised_Learning_From_Images_With_a_Joint-Embedding_Predictive_Architecture_CVPR_2023_paper.pdf)

训练时，从不同世界的完整演示中自动采样起点和终点，遮掉两者之间一段的观测及动作。用编码器得到公开历史的表示，从完整训练轨迹提取被遮挡位置的目标表示，目标表示不回传梯度。世界模型根据可见的起点历史、终局条件和时间信息预测这些中间表示。遮挡位置和长度可以变化。像「采集」「建造」这样的阶段由模型从轨迹中学习，训练只提供观测、动作、时间和任务结果。

**当前实现。** 编码器先作为重建式自编码器训练，然后冻结。预测器用 GRU 汇总公开历史，输入终局条件、剩余预算 b 和查询偏移 q，以及 b/B、q/B、q/b 这些时间特征，预测查询时刻的潜表示。另训练一个不看终局条件的预测器作对照。候选由残差条件流匹配采样：以预测值、当前观测和终局条件为条件，生成预测残差，用 16 步 Euler 积分。冻结能量是候选在参考样本下的核密度负对数（Scott 带宽，按潜变量维数归一化），只作基线。因为编码器是重建式训练的，在 SIGReg 预测式编码器的对照完成前，论文把方法称为掩码潜空间预测，不称为 JEPA 表示。[表示对照](latent-subgoal-research.md#10-isolate-the-representation-contribution)

受控任务和 E1 用的是另一条管线：每个潜候选解码成一个观测，投影成格子、图节点或观测，交给以观测为条件的执行器，并用精确格子、节点或人工容差判断到达。option 规划器不再解码，潜候选直接交给以潜目标为条件的 GCIVL 执行器。

训练轨迹的实际结尾可以提供终点样例。在线规划的输入是当前公开观测历史、终局要求和剩余预算。终局要求可以由多种状态满足。例如，「活到第三天」允许不同的地点、食物和庇护所。若部署时以任务条件表达终局，训练时也应使用这种输入。若部署时需要具体目标样例，则从训练数据取样。评估轨迹的真实未来只用于检验预测和执行结果。

## 采样候选，并把每个候选当作 option

在一次决策时，世界模型在每个查询偏移上采样多个潜未来，每个样本连同它的偏移就是一个候选 option：「追 z 至多 k 步」。编码后的终局目标也是一个候选，追满剩余预算。候选在剩余预算下采样，也在更短的预算下采样，因为以剩余预算为条件的补全会把路线的节奏拉到截止时刻。

- **在潜空间采样不同路线。** 给定同一起点和终局，世界模型可以给出多条中间表示序列。比如，一条路线先获得食物，另一条先找到过夜的地方。我们要检验采样是否覆盖不同的可行路线，以及选中的目标能否被执行。
- **由执行结果赋予含义。** 一个 z 意味着什么，由执行器追它时实际落在哪里决定。同一个 z 可以被不同的动作序列和不同的落点实现，价值从这些结果中学习，不需要事先给目标命名或划定边界。

「生存三天」这个例子只用来说明多条路线。论文先在 dependency grid 和 budget routes 两个受控任务上检验主张，再到 Maze2D 和 OGBench Scene 上验证。Craftax 的「期限内制作铁镐并在期限结束时存活」留作后续的复合终局任务。

## 判断哪个目标值得去

一个 option 的价值是：从当前历史出发，追 z 至多 k 步，然后按同一套规则继续，在剩余预算内完成终局的概率，减去每一步的时间成本 λ。错过之后仍然成功也计入，所以只看到达率或只看到达后的价值都会漏掉一部分。

**离线拟合。** 演示档案里从 s_t 到 s_{t+k} 的每一段，都是一个追 enc(s_{t+k}) 的 option；重标记的终局目标是追满整个预算的 option。半马尔可夫目标是：k 步内首次到达终局时为 1 − λd，预算用完时为 −λb，否则为 −λk + V(s_{t+k}, g, b − k)。V 是档案中实际追过的 option 上 Q 的上 expectile，避免在没人试过的候选上取最大值。备份没有折扣，所以 V 截断在仍然可能的回报范围 [−λ(b − k), 1 − λ] 内；不截断时每次备份都会叠加 expectile 的偏差，价值涨到 25，终局目标候选永远选不上。

**在线修正。** 演示从来没有专门去追终局目标，所以离线价值会误判执行器真正会追的 option。规划器在训练起点上跑几轮，按候选来源均匀探索，执行器的尝试和事后 option 混合后继续训练价值。报告终局成功率随尝试次数的变化，并让基线把同样的交互量用在更多演示或微调执行器上。

**执行中的选择。** 每一步重新给当前 option 和缓存的候选（包括终局目标）打分，某个候选比当前 option 高出价值头集成的离散度时就切换。只有时长用完、价值下降超过离散度、或编码后的观测偏离预测路径时，才重新采样候选。

已完成的受控实验在候选池上先声明候选和打分，再在共享起点和随机流上执行，用训练世界上的重复尝试拟合带岭正则的逻辑回归选择器，输入是人工设计的几何特征或公开状态转移表。新方法不再使用这些特征，价值只从世界模型的潜特征估计。

## 用实际执行反馈训练轨迹补全

**后续扩展（P2）。** 论文主线只用尝试结果训练 option 价值，生成器保持冻结。本节的生成器更新是后续扩展：用同起点下不同中间目标的实际尝试结果，让模型以后更常提出能可靠执行、且有助于完成终局的目标。检验在演示覆盖变少时，这种反馈能否在同等预算下同时提高低支持度目标的发现率和真实终局成功率。遮挡预测、条件生成和闭环执行组成同一套方法。候选贡献取决于共享比较协议下的结果。

1. **从演示预训练。** 用上文的掩码潜空间预测学习中间状态的表示。在这个空间中训练条件流匹配或扩散模型，根据当前公开历史、终局条件和剩余预算采样多条中间路线。每条路线首先给出一个目标及其尝试期限。执行器根据目标和实时观测选择动作，允许用不同动作实现同一目标。
2. **给候选收集可比较的执行反馈。** 在训练世界，对同一起点预先声明多个候选。配对重复执行，起点、任务、总预算、执行器与后续策略一致。每次只干预第一个目标及其期限，达到该目标或超时后交给共同的后续策略，直到终局。记录中间目标的执行情况和整次尝试的终局结果，包括错过中间目标却成功的情况。初版把反馈归到实际尝试的目标和期限。规划中未执行的后续目标可在新的起点另行收集反馈。
3. **用反馈选目标，也让反馈改变以后会提出的目标。** 先用监督学习拟合尝试后完成终局的概率，重排同一候选池。然后对实际验证过的中间目标和期限做加权生成训练。同时满足最低可达性要求、且在同起点比较中提高终局成功率的候选获得更大的权重。训练继续混合原来的完整演示，通过完整演示学习路线其余部分。用冻结生成器加同一个重排器作为对照，检验更新后是否确实会提出更好的候选。低频是评估维度，候选训练权重由执行结果决定。
4. **在测试世界闭环执行。** 从自然重置出发，模型用公开观测、终局要求和剩余预算生成候选并选下一目标。执行一段后根据新观测重规划。规划时的尝试成功率来自训练好的监督预测器，真实分支结果由评估器用于计分。用相同的终局判定比较仅给起点和终局的设定，以及额外提供粗略初始策略的设定。

### 指标与关键消融

- **终局成功率和首次成功步数。** 在独立持出起点上比较完整方法，报告按世界或起点配对的差值和不确定性。
- **低支持度且可靠的目标。** 用冻结的公共目标匹配规则和独立训练参考回合估计频率，每个回合对同类目标最多计一次。用独立重复确认可达性与后续成功，按相同提议预算报告能找出多少这类目标。把完整路线未出现过与中间目标本身低频分开计量。
- **定位收益。** 共享执行器和打分器，比较回放、单个潜空间方案和多个潜空间方案。共享候选池，比较按长度、按终点距离、按中间目标到达率、按整条轨迹成败训练的能量、按可达性过滤加价值和按整次尝试的终局成功率排序，并记录选择器训练用掉的模拟器尝试次数。共享重排器，比较更新前后生成器提出的目标。若要归因到 JEPA 式表示，再在共享生成和执行接口下比较遮挡预测与重建式表示。
