# 通过潜空间轨迹补全发现中间目标

我们想知道，智能体能否只根据当前观测和一个长程任务，发现演示中少见但能可靠执行的中间目标，再把这些目标串起来，提高它在新世界里的终局成功率。核心假设是，一段轨迹可以像一张被遮挡的图一样从两端向中间补全，而且同样的两端可以容纳多种可执行的路线。

**Worth reaching** 指模型学出的潜空间区域所代表的中间目标。判断一个目标值不值得去，要从同一起点尝试不同候选，在共享执行器、后续策略和总预算下测量整次尝试的终局成功率。对演示少见的目标，用独立演示估计支持度，并用独立的前瞻执行检验可靠性。潜空间表示来自模型，解码后的公开观测用于解释和执行，前瞻结果用于检验终局价值。

**论文主张。** 补全潜空间轨迹、在潜空间生成子目标、以潜目标为条件的执行器，这些部件都有先例（Diffuser、HorizonFlow、HDFlow、HWM、Director、Fast-JEPA）。论文的核心主张（A）是：**中间目标是潜空间里的一个 z，它的含义由条件生成分布 p(s | z) 定义，是一片状态区域，而不是某个具体状态。** 执行器直接以 z 为条件去追，在潜空间判断是否到达，解码器只在事后揭示模型发现了什么目标。价值估计方法（C）是在潜空间学习预算条件的 option 价值 Q(h, z, b)，用半马尔可夫 Bellman 备份拟合。支撑性的实证发现（B）是：模型似然不等于价值，预算会改变哪个目标值得去。目标的价值是同一起点、同一执行器、同样的剩余预算下尝试这片区域之后的终局成功率，它不同于模型似然、到达率、路线长度、到目标样例的潜空间距离，也不同于整条记录轨迹的成败标签。实验优先级和与已有工作的对照见[研究计划](latent-subgoal-research.md#positioning-against-prior-work)和[实施计划](../PLAN.md#paper-experiments-by-priority)。

## 从两端预测中间

在 I-JEPA 中，模型看到图像的一部分和被遮挡块的位置，预测该块的特征。训练答案来自编码过的完整图像。我们把图像上的空间位置换成轨迹上的时间位置，把可见的上下文换成起点历史和终局条件。[I-JEPA 原论文第 3 节与第 8 节](https://openaccess.thecvf.com/content/CVPR2023/papers/Assran_Self-Supervised_Learning_From_Images_With_a_Joint-Embedding_Predictive_Architecture_CVPR_2023_paper.pdf)

训练时，从不同世界的完整演示中自动采样起点和终点，遮掉两者之间一段的观测及动作。用编码器得到公开历史的表示，从完整训练轨迹提取被遮挡位置的目标表示，目标表示不回传梯度。世界模型根据可见的起点历史、终局条件和时间信息预测这些中间表示。遮挡位置和长度可以变化。像「采集」「建造」这样的阶段由模型从轨迹中学习，训练只提供观测、动作、时间和任务结果。

**当前实现。** 编码器先作为重建式自编码器训练，然后冻结。预测器用 GRU 汇总公开历史，输入终局条件、剩余预算 b 和查询偏移 q，以及 b/B、q/B、q/b 这些时间特征，预测查询时刻的潜表示。另训练一个不看终局条件的预测器作对照。候选由残差条件流匹配采样：以预测值、当前观测和终局条件为条件，生成预测残差，用 16 步 Euler 积分。冻结能量是候选在参考样本下的核密度负对数（Scott 带宽，按潜变量维数归一化），只作基线。因为编码器是重建式训练的，在 SIGReg 预测式编码器的对照完成前，论文把方法称为掩码潜空间预测，不称为 JEPA 表示。[表示对照](latent-subgoal-research.md#10-isolate-the-representation-contribution)

当前的解码器是确定性的。每个潜候选只解码成一个观测，再被投影成格子、图节点或观测，交给以观测为条件的执行器，并用精确格子、节点或人工容差判断到达。已完成的实验都用这条管线，所以它们检验的是解码出的点目标，还没有检验目标区域。

训练轨迹的实际结尾可以提供终点样例。在线规划的输入是当前公开观测历史、终局要求和剩余预算。终局要求可以由多种状态满足。例如，「活到第三天」允许不同的地点、食物和庇护所。若部署时以任务条件表达终局，训练时也应使用这种输入。若部署时需要具体目标样例，则从训练数据取样。评估轨迹的真实未来只用于检验预测和执行结果。

## 生成多条路线，并为每条路线生成可执行的实现

中间目标在生成时是一份模型学出的潜空间表示 `z`，也可以是潜状态序列中的一段。给定 `z`，生成式解码器 p(s | z) 给出与它相容的全部公开观测，`z` 因此代表一片目标区域。表示的含义由解码和后续实际执行揭示，无需预先给它命名，也无需在潜空间指定一个几何边界。

**目标区域的设计。** 解码器用条件扩散或流模型实现，训练数据是「预测出的潜表示 → 该查询时刻的真实未来观测」配对。若在「真实观测的编码 → 观测」配对上训练，回归到多个未来平均值的预测会落在编码流形之外，解码就不可靠。执行器 π(a | h, z) 直接以 z 为条件，用演示中对应时刻的潜目标训练，最好使用预测出的潜表示，让训练和部署的输入一致。到达有两种判据，先都试，再在开发集上决定：
- **编码一致性**：‖enc(s) − z‖ ≤ ε。计算便宜，但 z 落在两个模式之间时可能失效。
- **区域支持度**：log p(s | z) ≥ κ。跟随解码器给出的实现，但需要估计似然。

一片区域是否「一致」可以检验：从 p(s | z) 采样多个实现，分别作为点目标尝试，比较同一区域内的价值差异和不同区域之间的价值差异。区域粒度由 ε 或 κ 控制，需要在到达率和后续价值之间权衡。[区域实验](latent-subgoal-research.md#4-compare-region-goals-with-decoded-point-goals)

- **在潜空间采样不同路线。** 给定同一起点和终局，使用条件生成模型采样多组中间表示或中间表示序列。比如，一条路线可以先获得食物，另一条可以先找到过夜的地方。世界模型的预测可作为生成的条件。我们要检验生成结果是否覆盖了不同的可行路线，以及相邻目标能否顺序执行。
- **在同一潜空间方案下采样具体实现。** 同一个抽象目标可以允许多种资源配置和动作序列。比如，「获得足够食物」可以用苹果或其他食物实现。生成器可以提出与同一表示相容的候选落点。执行器接收当前观测、目标表示和预算，生成动作，再依据新观测调整。候选落点的可达性由实际动作和转移决定。

「生存三天」这个例子只用来说明两种多样性。论文先在 dependency grid 和 budget routes 两个受控任务上检验主张，再到 Maze2D 和 OGBench Scene 上验证。Craftax 的「期限内制作铁镐并在期限结束时存活」留作后续的复合终局任务。我们希望中间表示保留能连接前后两段轨迹的信息，例如区分那些需要用不同动作到达、接下来又能走不同路线的状态，即使它们的终局成功率相近。

## 判断哪个目标值得去

目标区域 ξ 的价值 W(ξ) 是：同一起点、同一执行器、同样的剩余预算下，把 ξ 交给执行器追到到达、超时或终止，再由共同的后续策略用实际剩余预算继续，最终完成终局的概率。ξ 的优势是 W(ξ) 减去直接执行的价值。错过目标后仍然成功也计入。W 可以分解为到达率乘以到达后的成功率，加上未到达率乘以未到达后的成功率，所以只看到达率或只看到达后的价值都会漏掉一部分。

测量时，候选和打分先写入候选池，再开始执行。各候选共享起点和随机流，训练、开发和测试世界互不重叠，区间按世界重采样。选择器是带岭正则的二项逻辑回归，输入公开特征，用训练世界上的重复尝试拟合。只有某个候选的预测成功率严格高于直接执行时，才改为追这个候选。预算路线任务把分别采样到的单个目标组合成有序的目标对，最多 24 个候选，用动态规划估计每条路线在实际预算下的成功率。同一个候选池在不同预算下重新排序，第一个目标结束后再重规划。

上面的逻辑回归选择器用蒙特卡洛标签：每次都把尝试跑到终局。计划把它换成预算条件的 option 价值：

```
Q(h, z, b) = E[ V(h', b − τ) ]        # 追 z 用了 τ 步，落在 h'（到达或未到达）
V(h, b)    = max( Q_direct(h, b), max_z Q(h, z, b) )
```

价值头读取潜特征：编码历史、候选潜表示、查询时刻的预测潜表示、预算和查询偏移。Bellman 备份只需要单段尝试，后半段由学到的 V 自举，模拟器调用更少，也让世界模型同时负责提出候选和估计价值。蒙特卡洛选择器保留为参照，匹配干预测出的真实价值是所有学到的价值的评估基准。多步组合直接在 V 上规划：深度为 2 时枚举有序对并做动态规划；深度更大时用价值引导生成区域序列，在相同推理预算下和枚举比较。

论文需要补的对照：
- **区域与点目标。** 同一批潜候选，比较解码点目标和两种到达判据下的区域目标，并扫描区域粒度。
- **监督来源。** 在同一个区域候选池上比较 option 价值、HDFlow 式的整条轨迹成败能量、HECRL 式的可达性过滤加价值、只看到达率、HorizonFlow 式的长度和 Fast-JEPA 式的终点距离。
- **交互量。** 记录拟合价值用掉的模拟器尝试次数，画出终局成功率随尝试数变化的曲线，并让基线把同样的交互量用在更多演示或微调执行器上。

## 从执行结果改进策略

在线时，规划器从真实起点提出几条候选路线，选择一个下一目标，执行一段，再用新观测和剩余预算补全余下轨迹。达到当前候选、超时或可行性变化都可以触发重规划。执行时如何判断进展是单独的设计问题，主要实验直接测量执行完整策略后的终局成功率。已完成的实验每个起点只做一次高层选择，预算路线另有一次重规划。多步闭环决策是下一步的对照，以固定间隔重规划和单次选择为基线，在相同模型调用次数下比较。主设定只给起点和终局。给一条粗略初始策略（例如「第一天找食物，第二天找木材」）、让模型补全或重排其中步骤的设定留作后续。

演示提供初始训练数据。后续用实际尝试的终局成败重排候选，并在获得新的环境反馈后检验是否可以更新提议器。一次尝试从选定目标算起，包含尝试期间用掉的动作和剩余预算下的延续。即使未到达中间目标，只要最后完成任务也计为终局成功。采样重排和使用新轨迹继续训练都可以直接用这一终局信号。

## 用实际执行反馈训练轨迹补全

**后续扩展（P2）。** 论文主线只用尝试结果训练选择器，生成器保持冻结。本节的生成器更新是后续扩展：用同起点下不同中间目标的实际尝试结果，让模型以后更常提出能可靠执行、且有助于完成终局的目标。检验在演示覆盖变少时，这种反馈能否在同等预算下同时提高低支持度目标的发现率和真实终局成功率。遮挡预测、条件生成和闭环执行组成同一套方法。候选贡献取决于共享比较协议下的结果。

1. **从演示预训练。** 用上文的掩码潜空间预测学习中间状态的表示。在这个空间中训练条件流匹配或扩散模型，根据当前公开历史、终局条件和剩余预算采样多条中间路线。每条路线首先给出一个目标及其尝试期限。执行器根据目标和实时观测选择动作，允许用不同动作实现同一目标。
2. **给候选收集可比较的执行反馈。** 在训练世界，对同一起点预先声明多个候选。配对重复执行，起点、任务、总预算、执行器与后续策略一致。每次只干预第一个目标及其期限，达到该目标或超时后交给共同的后续策略，直到终局。记录中间目标的执行情况和整次尝试的终局结果，包括错过中间目标却成功的情况。初版把反馈归到实际尝试的目标和期限。规划中未执行的后续目标可在新的起点另行收集反馈。
3. **用反馈选目标，也让反馈改变以后会提出的目标。** 先用监督学习拟合尝试后完成终局的概率，重排同一候选池。然后对实际验证过的中间目标和期限做加权生成训练。同时满足最低可达性要求、且在同起点比较中提高终局成功率的候选获得更大的权重。训练继续混合原来的完整演示，通过完整演示学习路线其余部分。用冻结生成器加同一个重排器作为对照，检验更新后是否确实会提出更好的候选。低频是评估维度，候选训练权重由执行结果决定。
4. **在测试世界闭环执行。** 从自然重置出发，模型用公开观测、终局要求和剩余预算生成候选并选下一目标。执行一段后根据新观测重规划。规划时的尝试成功率来自训练好的监督预测器，真实分支结果由评估器用于计分。用相同的终局判定比较仅给起点和终局的设定，以及额外提供粗略初始策略的设定。

### 指标与关键消融

- **终局成功率。** 在独立持出起点上比较完整方法，报告按世界或起点配对的差值和不确定性。
- **低支持度且可靠的目标。** 用冻结的公共目标匹配规则和独立训练参考回合估计频率，每个回合对同类目标最多计一次。用独立重复确认可达性与后续成功，按相同提议预算报告能找出多少这类目标。把完整路线未出现过与中间目标本身低频分开计量。
- **定位收益。** 共享执行器和打分器，比较回放、单个潜空间方案和多个潜空间方案。共享候选池，比较按长度、按终点距离、按中间目标到达率、按整条轨迹成败训练的能量、按可达性过滤加价值和按整次尝试的终局成功率排序，并记录选择器训练用掉的模拟器尝试次数。共享重排器，比较更新前后生成器提出的目标。若要归因到 JEPA 式表示，再在共享生成和执行接口下比较遮挡预测与重建式表示。
